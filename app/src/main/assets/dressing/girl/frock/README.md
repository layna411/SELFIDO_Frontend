# GIRL FROCK DRESSING ANIMATION ASSETS (18 STEPS)

Place the following GIF/WebP files in this directory (`assets/dressing/girl/frock/`):

1. `step_01_look.gif` - Look at the Frock
2. `step_02_pickup.gif` - Pick up the Frock
3. `step_03_front_back.gif` - Identify front and back tag
4. `step_04_neck.gif` - Find neck opening
5. `step_05_shoulders.gif` - Hold Frock at shoulder straps
6. `step_06_chest.gif` - Lift Frock to chest level
7. `step_07_head.gif` - Put head through neck opening
8. `step_08_pull_down.gif` - Pull Frock down past head
9. `step_09_right_armhole.gif` - Find right armhole
10. `step_10_right_arm.gif` - Put right arm through armhole
11. `step_11_right_shoulder.gif` - Pull right sleeve to shoulder
12. `step_12_left_armhole.gif` - Find left armhole
13. `step_13_left_arm.gif` - Put left arm through armhole
14. `step_14_left_shoulder.gif` - Pull left sleeve to shoulder
15. `step_15_front.gif` - Pull dress front down
16. `step_16_back.gif` - Pull skirt back down
17. `step_17_straighten.gif` - Straighten & adjust frock
18. `step_18_complete.gif` - Check comfortable fit (Princess Victory Stars)

Note: If any GIF file is absent at runtime, the SELFIDO fallback animation player renders a dynamic interactive step placeholder seamlessly.

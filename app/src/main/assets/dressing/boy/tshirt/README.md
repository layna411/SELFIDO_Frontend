# BOY T-SHIRT DRESSING ANIMATION ASSETS (18 STEPS)

Place the following GIF/WebP files in this directory (`assets/dressing/boy/tshirt/`):

1. `step_01_look.gif` - Look at the T-shirt
2. `step_02_pickup.gif` - Pick up the T-shirt
3. `step_03_front_back.gif` - Identify front and back tag
4. `step_04_neck.gif` - Find neck opening
5. `step_05_shoulders.gif` - Hold T-shirt at shoulder areas
6. `step_06_chest.gif` - Lift T-shirt to chest level
7. `step_07_head.gif` - Put head through neck opening
8. `step_08_pull_down.gif` - Pull T-shirt down
9. `step_09_right_sleeve.gif` - Find right sleeve
10. `step_10_right_arm.gif` - Put right arm through sleeve
11. `step_11_right_shoulder.gif` - Pull right sleeve toward shoulder
12. `step_12_left_sleeve.gif` - Find left sleeve
13. `step_13_left_arm.gif` - Put left arm through sleeve
14. `step_14_left_shoulder.gif` - Pull left sleeve toward shoulder
15. `step_15_front.gif` - Pull front down
16. `step_16_back.gif` - Pull back down
17. `step_17_straighten.gif` - Straighten T-shirt
18. `step_18_complete.gif` - Check comfortable positioning (Victory Stars)

Note: If any GIF file is absent at runtime, the SELFIDO fallback animation player renders a dynamic interactive step placeholder seamlessly.
